## 复现方式（browser-use 浏览器自动化）

1. 按 README 快速开始起服务并写入演示数据：`pnpm demo:seed`（保证画像/推荐/学习进度非空）、`pnpm dev`。
2. 用浏览器自动化按上表逐页访问；登录态通过页面内调用 `POST /api/auth/login`（演示账号）获得，
   随后整页刷新让 SSR 渲染登录后顶栏。
3. 统一视口 1440×900；截图前移除 Nuxt DevTools 角标（`#nuxt-devtools-container` 等开发期悬浮元素），
   保证成品干净。
4. 课程审核页默认「待审核」为空（演示数据全部已发布），截图时把筛选切到「已发布」。

> 截图为 2026-10-25 本地开发环境实拍；条目图片为 Wikimedia Commons 外链（图集逐张标注 credit），
> 课程卡片无配图时显示占位图标，均属演示数据形态而非缺陷。
