# 0001 - 复杂工程问题界定：学习者画像推荐 + 热点内容并发缓存

课程报告（第 4.1/4.2 章）要求界定"复杂工程问题"。薪火界定为两个：(1) 基于学习行为的学习者画像与个性化推荐——自实现 K-Means 聚类（含手肘法选 k）+ 技艺条目标签 TF-IDF 余弦相似度推荐，node-cron 每日离线计算；(2) 热点技艺条目详情页的高并发访问——Redis cache-aside 缓存 + 互斥重建（singleflight 防击穿）+ 空值缓存（防穿透）。

刻意不接入任何第三方 AI/情绪分析 API：报告附录需要自研源码自圆其说，且演示当天不依赖外部配额与网络。此界定牵动报告第 4/5/6 章主体，中途更换成本极高。
